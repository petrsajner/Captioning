01 / DATASET RECIPE

One recipe.
The whole dataset.

Shared instructions for all selected images.

Video model captions are English descriptions. Each model gets its own caption file; the others are not changed.

FIBO JSON uses a fixed structure instead of tags or a word target. Responses are not capped; incomplete JSON is repaired automatically when possible.

The word count is a soft target. Captions up to 120% are kept; longer text is shortened by the model. Text is never mechanically truncated.
