1Co Caption Studio dělá

Caption Studio píše tréninkové popisky pro LoRA datasety. Nastavíte jeden recept pro celou sadu, vyberete obrázky nebo videoklipy a aplikace uloží ke každému originálu soubor s popiskem.

  • Obrazové modely: prosté popisy nebo tagy v .txt (FLUX.2, Klein, Z-Image, Krea 2, Qwen-Image, SDXL a každý trenér, který čte k obrázku soubor .txt) a strukturovaný .json pro BRIA FIBO.
  • Video modely: samostatný soubor popisku pro WAN 2.2 (text na video i obrázek na video), LTX-2.5 a MiniMax H3, každý v podobě, jakou používají jeho prompty. Fotky a klipy mohou být v jednom datasetu.
  • Čtyři druhy LoRA: postava nebo osoba, objekt nebo produkt, vizuální styl nebo obecný dataset. Každý druh pojmenovává svůj subjekt po svém a nabízí vlastní výběr detailů.
  • Tři způsoby, jak spustit obrazový model: cloudové API; lokální server, především Marvin, náš lokální harness pro Qwen (nebo Ollama, LM Studio, llama.cpp a další); nebo model, který si Caption Studio stáhne a spouští samo.

Rychlý start

  1. Nainstalujte a spusťte Caption Studio (kapitola 2).
  2. V nastavení připojte cloudové API nebo Marvina (případně jiný lokální server), nebo stáhněte model (kapitola 3).
  3. Klikněte na ＋ Otevřít složku a vyberte složku s datasetem.
  4. V receptu zvolte Co trénujete?, Výstup popisků a jméno, které se má LoRA naučit.
  5. Klikněte na Vytvořit popisky a výsledky zkontrolujte v pravém panelu.
Grafická karta není potřeba Caption Studio běží na každém počítači s Windows 10 nebo 11. S cloudovým API analyzuje obrázky poskytovatel, takže výkonnou grafickou kartu nepotřebujete. Karta je nutná, jen pokud chcete model spouštět na vlastním počítači.
DOPORUČENO

Lokální popisování s Marvinem

S kartou NVIDIA (16 GB a víc) spouštějte model na vlastním počítači s Marvinem, naším lokálním AI harnessem pro Qwen3.8 27B (github.com/petrsajner/marvin). Spusťte Marvina a Caption Studio ho najde jedním kliknutím: zdarma, soukromě a se stejným modelem pro obě aplikace. Viz 3.1.

3.1 Marvin: doporučený lokální model

DOPORUČENO

Marvin je lokální AI harness pro Qwen3.8 27B na grafických kartách NVIDIA od autora Caption Studia. Kromě toho, že poskytuje model Caption Studiu, je to úplný lokální asistent: chat, programovací agent, analýza obrázků, rešerše a další. Model, konverzace i soubory zůstávají na vašem počítači.

  • Stejný obrazový model Qwen3.8 27B jako vlastní stažení Caption Studia, s podporou obrázků.
  • Profily změřené na skutečných kartách; údaje o paměti grafické karty v této příručce pocházejí z Marvina.
  • Velký kontext (až 192k tokenů), takže se vejdou i klipy s 30 snímky.
  • Jeden model pro obě aplikace: v Caption Studiu už nic dalšího nestahujete.

Stažení: github.com/petrsajner/marvin, Full installer (doporučený pro nový počítač; obsahuje vše a model stáhne během instalace).

  1. Nainstalujte a spusťte Marvina. Marvin sám spustí svůj server modelu na adrese http://127.0.0.1:8080/v1.
  2. V nastavení Caption Studia klikněte na ◎ Lokálně a pak na Najít lokální servery.
  3. Klikněte na server http://127.0.0.1:8080/v1. Caption Studio ho uvádí jako obvyklou adresu Marvina / llama.cpp. Adresa i model (například q5) se vyplní samy; klíč není potřeba.
  4. Klikněte na Uložit a pokračovat →.
Uvažování Lokální Qwen při popisu obrázku uvažuje a zkracuje bez uvažování: dělá tak zhruba poloviční počet chyb a trvá asi 23 s na popisek na RTX 5090. Server, na kterém uvažování zapnout nejde, dostane upozornění, že jeho popisky budou méně přesné.
Při popisování nechte Marvina běžet Caption Studio Marvina nikdy nespouští ani neukončuje. Zavřením Marvina se model zastaví a grafická karta se uvolní, například před tréninkem LoRA.

3.2 Cloudové API

  1. Klikněte na ☁ Cloudové API.
  2. Zvolte Poskytovatele: OpenRouter, OpenAI, Google Gemini, nebo Jiné kompatibilní API. Adresa API se vyplní sama; u jiného poskytovatele zadejte jeho základní adresu (HTTPS, obvykle končí na /v1).
  3. Vložte API klíč. Získáte ho v účtu poskytovatele, například v Google AI Studiu (Gemini), na platformě OpenAI nebo v OpenRouteru v části Keys.
  4. Klikněte na Načíst dostupné modely a vyberte Model s podporou obrázků, například gemini-3.8-flash. Přesné ID modelu můžete také napsat.
  5. Klikněte na Uložit a pokračovat →.

Klíč se ukládá šifrovaně pro váš účet Windows a jen pro danou adresu API; každý poskytovatel má vlastní klíč. Když je klíč uložený, prázdné pole ho ponechá. Smažete ho zaškrtnutím Odstranit uložený klíč tohoto poskytovatele a uložením.

Vyberte model, který přijímá obrázky Seznam může obsahovat i čistě textové modely. Pokud model obrázky odmítne, zvolte jiný. U videoklipů dostane model v jednom požadavku až 30 snímků.

Doporučené modely

Nastavení cloudu ukazuje v zelené zóně doporučené modely seřazené podle kvality a v červené zóně modely, které nedoporučujeme. U každého je vidět kvalita (1–5 dílků), čas na popisek a cena za 100 popisků; kliknutím se zobrazí podrobnosti. Použít tento model vyplní ID modelu pro zvoleného poskytovatele; když ho zvolený poskytovatel nenabízí, přepne na OpenRouter. Pak stačí uložit.

3.3 Jiné lokální servery

Stejně funguje každá jiná aplikace, která poskytuje obrazový model přes API kompatibilní s OpenAI. Model zůstává ve své aplikaci; Caption Studio se k němu jen připojí a nikdy ho nespouští ani neukončuje.

  1. Ve své aplikaci spusťte API server a načtěte v ní obrazový model.
  2. V nastavení klikněte na ◎ Lokálně a Najít lokální servery; klikněte na server, který odpověděl.
  3. Nebo zvolte Způsob připojení → Existující lokální server a Adresu lokálního API zadejte sami.
  4. Pokud server vyžaduje klíč (například Unsloth), zadejte Lokální API klíč.
  5. Klikněte na Načíst modely, vyberte Model s podporou obrázků a klikněte na Uložit a pokračovat →.
Aplikace Obvyklá adresa
Marvin http://127.0.0.1:8080/v1
Ollama http://127.0.0.1:11434/v1
LM Studio http://127.0.0.1:1234/v1
llama.cpp (llama-server) http://127.0.0.1:8080/v1
Unsloth, vLLM http://127.0.0.1:8000/v1, :8888/v1
Co musí lokální model zvládnout V lokálním režimu jsou povolené jen lokální adresy (localhost, 127.0.0.1). Model v seznamu nemusí umět obrázky, proto vyberte obrazový model. Pro klipy musí přijmout až 30 obrázků v jednom požadavku; dejte mu velký kontext (aspoň 64k tokenů). Marvin to všechno splňuje bez dalšího nastavování.

3.4 Vlastní stažený model

Caption Studio si umí model stáhnout a spouštět i samo: Qwen3.8 27B s obrazovou částí na přibaleném prostředí llama.cpp. Hodí se, když chcete Caption Studio samotné; s Marvinem tento oddíl přeskočte.

  1. Klikněte na ◎ Lokálně a zvolte Způsob připojení → Vlastní prostředí Caption Studio.
  2. Vyberte profil v poli Model podle své grafické karty (tabulka níže).
  3. Zvolte Výpočet: NVIDIA · CUDA 13.3 pro karty NVIDIA, AMD / Intel / NVIDIA · Vulkan pro ostatní karty, nebo Procesor · pomalé bez vhodné karty.
  4. Klikněte na Stáhnout prostředí a model. Průběh ukazuje ukazatel; Pozastavit stahování přeruší a další pokus naváže tam, kde skončilo. Každý soubor se před použitím ověří (SHA-256).
  5. Když štítek ukáže Připraveno, klikněte na Uložit a pokračovat →. Model se spustí sám s první dávkou; Spustit model ho spustí hned.

Uvolnit GPU model zastaví a uvolní paměť grafické karty, například před tréninkem. Zavřením Caption Studia se model také zastaví.

3.5 Podporované grafické karty

Všechny čtyři profily jsou stejný model Qwen3.8 27B v různé přesnosti. Vybírejte podle paměti grafické karty (VRAM):

Profil Stažení Grafická karta Změřená VRAM Volný disk Poznámka
Q2 9,8 GB 16 GB 13,0 GiB ≈ 13 GB Nejmenší; obrázky se zpracují na grafické kartě
IQ3 12 GB 16 GB 13,6 GiB ≈ 15 GB Obrázky se zpracují na procesoru: pomalejší, asi 3 minuty na klip s 30 snímky
Q4 16,5 GB 24 GB 18,9 GiB ≈ 20 GB Výchozí. Asi 18 s na klip s 30 snímky
Q5 19,8 GB 32 GB – ≈ 23 GB Nejvyšší přesnost

VRAM změřil Marvin na RTX 5090 s kontextem 64k a nezahrnuje jiné programy. Volné místo na disku zahrnuje obrazovou část modelu (0,93 GB) a prostředí (asi 2 GB). Marvin spouští stejný model na stejných změřených profilech, takže tabulka platí i pro něj.

  • NVIDIA s 16 GB a víc (například RTX 4080, 4090, 5080, 5090): Marvin, nebo výpočet CUDA vlastního modelu. Udržujte ovladač NVIDIA aktuální.
  • AMD Radeon nebo Intel Arc s 16 GB a víc: výpočet Vulkan. Je k dispozici, ale není vyzkoušený na každé kartě.
  • Méně než 16 GB nebo bez grafické karty: použijte cloudové API, nebo lokální server s menším obrazovým modelem. Výpočet na procesoru funguje, ale je velmi pomalý.

3.6 Zbytek nastavení

Jazyk rozhraní okamžitě přepne aplikaci mezi angličtinou a češtinou. Jazyk popisků tím nemění; ten se nastavuje v receptu.

Nastavení Volby Co dělá
Nejdelší strana pro analýzu 768, 1 024, 1 536, 2 048 px Model dostane kopii zmenšenou na tuto velikost. Větší ukáže víc detailů, ale je pomalejší a v cloudu dražší.
Čas na obrázek (s) 30–900, výchozí 240 Jak dlouho čekat na jednu odpověď. U pomalého modelu nebo dlouhých klipů hodnotu zvyšte.
Snímky z klipu pro analýzu Každých 0,25, 0,5 nebo 1 s Jak často se z klipu bere snímek. Nejvýš 30 snímků o velikosti asi jednoho megapixelu; delší klipy dostanou 30 rovnoměrně rozložených snímků.

Originály se nikdy nemění: model dostává zmenšenou kopii bez EXIF metadat. Nastavení uložíte tlačítkem Uložit a pokračovat →.

5Krok za krokem: od obrázků k popiskům

  1. Připravte složku. Obrázky (a klipy) jednoho datasetu dejte do jedné složky, s jedinečnými názvy souborů. Viz kapitola 6.
  2. Načtěte ji. Klikněte na ＋ Otevřít složku, najděte složku v náhledu a klikněte na Použít tuto složku. Všechny obrázky se objeví jako karty; už existující popisky jsou označené Existující.
  3. Řekněte, co trénujete. V poli Co trénujete? zvolte Postava / osoba, Objekt / produkt, Vizuální styl nebo Obecný dataset a vyplňte jméno (u postavy a objektu také jeho typ).
  4. Zvolte výstup. V poli Výstup popisků vyberte soubor pro model, který budete trénovat, například Normal · .txt pro FLUX.2 nebo Všechny video modely pro WAN, LTX a H3.
  5. Zvolte detaily. Zaškrtněte, co má zůstat měnitelné promptem; odškrtněte, co se má naučit LoRA. Použít výchozí volby pro tento typ LoRA je dobrý začátek.
  6. Zkontrolujte zadání (nepovinné). Zobrazit výsledné zadání ↗ ukáže přesně, co model dostane.
  7. Nejdřív vyzkoušejte pár obrázků. Zrušte Vybrat vše, zaškrtněte dvě tři karty a klikněte na Vytvořit popisky. Přečtěte si výsledky; recept podle potřeby upravte.
  8. Popište zbytek. Zaškrtněte Vybrat vše a klikněte na Vytvořit popisky. Se zapnutým Přeskočit existující popisky se hotové obrázky znovu nezpracují.
  9. Zkontrolujte. Vyfiltrujte Ke kontrole a Chyby, klikněte na každou kartu, opravte popisek a uložte ho klávesami Ctrl+S. Pro nový pokus použijte ↻ Znovu.
  10. Trénujte. Soubory popisků leží vedle obrázků; nasměrujte trenér (například LORA Train) na složku. Viz kapitola 13.

6Příprava datasetu

Caption Studio obrázky popisuje; neořezává je, nemění jejich velikost ani je nepřevádí. Dataset připravte před popisováním. Úplný návod k dobrému LoRA datasetu (kolik obrázků, pestrost, rozlišení pro jednotlivé modely) je v příručce LORA Train; tady je to podstatné.

Obrázky

  • Nejlépe fungují čtvercové obrázky, například 1024 × 1024 px. Většina trenérů zvládne i jiné poměry stran (bucketing), ale čtvercový výřez drží subjekt velký a jednotný.
  • Ostré, dobře nasvícené obrázky bez vodoznaků, rámečků a koláží. Odstraňte téměř shodné snímky.
  • Pestrost v tom, co má zůstat volné: u postavy různá pozadí, světla, pózy a oblečení; u stylu různé motivy.
  • Podporované formáty: JPG, JPEG, PNG, WEBP, BMP, TIF, TIFF. Vícesnímkové (animované) obrázky podporované nejsou.
  • Jedinečné názvy: foto.jpg a foto.png by sdílely foto.txt. Caption Studio takový konflikt ohlásí před zápisem; jeden ze souborů přejmenujte.

Videoklipy

Podporované formáty: MP4, MOV, WEBM, MKV, M4V, AVI. Klipy před popisováním zkraťte na délku, na které se model trénuje; Caption Studio je jen čte a nikdy je nemění.

Model Trénuje se na
WAN 2.2 (A14B) 16 fps, nejvýš 81 snímků, asi 5 s
WAN 2.2 I2V (A14B) 16 fps, nejvýš 81 snímků, asi 5 s; první snímek je výchozí obrázek
LTX-2.5 24–25 fps, nejvýš 121 snímků, asi 5 s
MiniMax H3 24 fps, klipy dlouhé 5–15 s

Jméno, které se LoRA naučí (trigger)

  • Použijte jedno vymyšlené, čitelné slovo, které základní model nezná: Velmira pro postavu, Zorbo pro objekt, Zorvak pro styl.
  • Vyhněte se krátkým tokenům jako sks; trenéry je najdou i uvnitř jiných slov. Nepoužívejte jména skutečných lidí ani značek.
  • V Caption Studiu i v trenéru používejte stejné jméno.

Existující popisky

Pokud složka už obsahuje soubory popisků, načtou se a zobrazí jako Existující. Se zapnutým Přeskočit existující popisky se zpracují jen obrázky bez souboru zvoleného výstupu.

7Nastavení sady (recept)

Recept v levém panelu platí pro všechny vybrané obrázky. Každá změna se ukládá automaticky (dole v panelu se objeví Nastavení uloženo).

7.1 Co trénujete?

Tato volba určuje, jak každý popisek pojmenuje to, co se LoRA učí, která pole vyplňujete a z jakých detailů vybíráte.

Typ Pole Popisek začíná
Postava / osoba Jméno postavy, Typ postavy Velmira, a woman, sits…; dál „the woman“ nebo „she“
Objekt / produkt Název předmětu, Typ předmětu Zorbo, a backpack, hangs…; dál „the backpack“ nebo „it“
Vizuální styl Název stylu Zorvak style, a woman sits…
Obecný dataset Trigger slovo (nepovinné) ohwx, a woman sits…

Postava a objekt: jméno a typ se zapíšou jednou, tam, kde je subjekt poprvé zmíněn. Typ (a woman, a man, a backpack) modelu říká i to, jaká zájmena použít. Pište ho v jazyce popisků; popisky pro video jsou vždy anglicky.

Vizuální styl: popisek popisuje jen obsah (lidi obecně), nikdy médium ani techniku, takže styl patří ke jménu. Název, který už končí slovem „style“, se použije tak, jak je.

Obecný: prostý popis; trigger slovo, pokud ho zadáte, stojí na začátku.

7.3 Formát, jazyk a délka

  • Formát: Popis (věty) nebo Tagy (oddělené čárkou). Platí pro popisky Normal.
  • Jazyk popisků: English nebo Čeština, pro Normal a pro hodnoty v BRIA JSON (klíče zůstávají anglicky). Popisky pro video jsou vždy anglicky.
  • Cílová délka: 20–300 slov, výchozí 100, včetně jména. Je orientační: popisky do 120 % zůstanou celé; delší model zkrátí. Text se nikdy mechanicky neořezává. BRIA JSON cílovou délku nemá.
  • Pod posuvníkem je nejkratší spolehlivá délka pro zvolený model a počet zapnutých detailů (u GPT, Claude, Qwen Max a Groku asi 4,5 slova na detail, u Gemini, Muse, GLM, lokálního Qwenu a každého dalšího modelu 6,5). Je to jen doporučení; kratší cíl se zvýrazní žlutě, ale nic se neomezuje.

7.4 Co přidat do popisu

Tohle je nejdůležitější část receptu. Pravidlo: co popisek popisuje, zůstane měnitelné promptem; co vynechá, to se naučí LoRA.

  • ON (zaškrtnuto) = popsáno v každém popisku = volně měnitelné v budoucích promptech.
  • OFF (nezaškrtnuto) = vynecháno = fixováno v LoRA.

Příklad: u postavy vynecháte obličej a barvu vlasů (naučí se je LoRA), ale popíšete účes, oblečení a pozadí, takže později můžete zadat „Velmira s culíkem, v červeném kabátě, na pláži“.

Každý typ má vlastní detaily a pamatuje si vlastní volby: přepnutí typu ukáže detaily daného typu a návrat obnoví, co jste pro něj zvolili. Použít výchozí volby pro tento typ LoRA vynechá detaily vyznačené níže tučně. Řádek nad seznamem ukazuje, kolik detailů je v popisu.

Typ Detaily (tučně = výchozí OFF)
Postava / osoba Identita / vzhled subjektu, Barva vlasů, Účes, Oblečení, Doplňky, Póza a činnost, Výraz obličeje, Prostředí a pozadí, Osvětlení, Kompozice a kamera, Vizuální styl
Obecný dataset Stejné detaily jako u postavy; ve výchozím stavu jsou všechny ON
Objekt / produkt Vzhled předmětu, Logo a text na předmětu, Varianta a stav, Umístění a natočení, Použití a interakce, Prostředí a pozadí, Osvětlení, Kompozice a kamera, Médium
Vizuální styl Co je na obrázku, Póza a činnost, Prostředí a pozadí, Světelná situace, Kompozice a kamera, Médium a technika, Barevná paleta a grading
Klipy (každý typ) Pohyb v čase, Pohyb kamery: zobrazí se, když je zvolen video výstup
Zelené, oranžové a zašedlé přepínače Každý přepínač jsme změřili na každém modelu z tabulky: kolik testovacích popisků ho dodrželo, když ho přepnete (detail ve výchozím stavu vynechaný zapnete, jakýkoli jiný vypnete). Zelený, víc než 85 % popisků: nabízí se normálně. Oranžový, 50–85 %: přepínač funguje, ale ne pokaždé; poznámka pod ním říká, kolik testovacích popisků ho dodrželo, takže popisky zkontrolujte. Zašedlý, pod 50 %: detail zůstane ve výchozím stavu typu LoRA a pod ním je důvod; recept si vaši volbu pamatuje a s modelem, který ji zvládne, se vrátí. Vizuální styl se hodnotí volněji (zelený nad 70 %, oranžový od 30 %), protože únik tam vadí méně než u postavy. Tabulka modelů v nastavení ukazuje oranžové a zašedlé přepínače každého modelu. Model, který v tabulce není, dostane všechny přepínače.

Tipy pro jednotlivé typy

  • Postava: barva vlasů a účes jsou oddělené. Barva vlasů postavy obvykle patří do LoRA; účes (rozpuštěné vlasy, culík, ofina) zůstává volný. Pokud postava nosí pořád stejný oděv a má být součástí LoRA, vypněte Oblečení.
  • Objekt: lidé, kteří předmět drží nebo používají, se popisují obecně. Pokud produkt existuje v několika barevných variantách, které mají zůstat měnitelné, napište to do Vlastních pokynů; Varianta a stav pak variantu pojmenuje.
  • Vizuální styl: Světelná situace popisuje denní dobu a zdroje světla; způsob, jak je světlo vykreslené, patří ke stylu. Barvy jednotlivých věcí se popisují i s vypnutou paletou.

Načtení

  • ＋ Otevřít složku otevře náhled složky s miniaturami, stromem složek, řádkem s cestou a tlačítky ← Zpět, Vpřed →, ↑ O složku výš, ⌂ Domů a ↻ Obnovit. Složku načtete tlačítkem Použít tuto složku.
  • ＋ Vybrat obrázky otevře výběr souborů Windows pro jednotlivé soubory.
  • Cesta… umožní vložit cestu ke složce přímo.
  • Včetně podsložek načte i obrázky v podsložkách.
  • Přidat k otevřené sadě přidá nové obrázky k aktuálnímu seznamu; bez něj nová složka seznam nahradí (žádné soubory se nemažou).

Jeden dataset pojme až 20 000 souborů. Dataset i neuložené návrhy zůstanou zachované i po zavření aplikace.

Vybrat vše vybere vše, co ukazuje aktuální filtr. Hledat můžete podle názvu souboru a filtrovat podle Všechny, Bez popisku, S popiskem, Chyby nebo Ke kontrole. Velké datasety se zobrazují po 60 kartách na stránku.

10Vytváření popisků

  1. Vyberte obrázky a klipy (zaškrtávací políčka nebo Vybrat vše).
  2. Klikněte na tlačítko vpravo dole. Jeho popis se řídí výstupem: Vytvořit popisky (5), Vytvořit BRIA JSON, Vytvořit popisky WAN 2.2, Vytvořit popisky pro všechny video modely. Číslo je počet vybraných položek.
  3. Obrázky se zpracovávají jeden po druhém. Spodní lišta ukazuje aktuální soubor a průběh; karty mění stav, jak se dokončují.
  • Zastavit dávku dávku zastaví. Uložené popisky zůstanou; dosud přijatá odpověď se zachová jako návrh.
  • Když selže spojení s modelem, dávka se pozastaví. Odstraňte příčinu a klikněte na Pokračovat: hotové obrázky se neopakují. Zahodit dávku ji místo toho ukončí. I po restartu lze přerušenou dávku stejně dokončit.
  • S vlastním modelem první dávka model spustí; jeho načtení do paměti grafické karty chvíli trvá.

Co se děje automaticky

  • Délka: popisek delší než 120 % cíle se pošle zpět ke zkrácení (nejvýš dva pokusy). Pokud je pořád dlouhý, zůstane nejkratší úplná verze s upozorněním.
  • Neúplné konce model doplní; pokud se to nepodaří, návrh zůstane Ke kontrole.
  • BRIA JSON se ověří a v případě potřeby opraví; neopravená odpověď zůstane návrhem ke kontrole.
  • Jméno se vloží tam, kde je subjekt poprvé zmíněn. Pokud ho model pojmenoval víckrát, další zmínky použijí jeho typ.
  • Existující popisky se nikdy neztratí: nahrazovaný soubor se nejprve zazálohuje.
  • Uvažování: model uvažuje, když se dívá na obrázek; zkracování a dokončení jde s nejnižším uvažováním, které poskytovatel přijme (rychlejší a levnější, kvalita beze změny).
  • Odpověď, která není popisek (zpráva uživateli nebo zbloudilá značka jako <characters>), zůstane Ke kontrole; nic se nemaže.
  • Chyba poskytovatele ukáže i jeho vlastní zprávu, například o potvrzení věku nebo došlém kreditu.

11Kontrola a úprava popisků

Kliknutím na kartu ji otevřete v pravém panelu.

  • Záložky nad editorem ukazují všechny soubory popisků obrázku (.txt, .json, .wan.txt…); fajfka znamená, že soubor existuje. Vpravo je počet slov.
  • Upravte text a klikněte na Uložit popisek nebo stiskněte Ctrl+S. Předchozí verze zůstane ve složce .caption-backups vedle obrázků.
  • ↻ Znovu vytvoří popisek otevřené záložky znovu, jen pro tento obrázek.
  • Odpovědi modelu uchovávají každou odpověď, kterou model vrátil (původní i zkrácenou). Vyberte jednu a klikněte na Vložit do editoru.
  • Upozornění pod editorem vysvětlují, co se stalo, například „Jméno bylo doplněno na začátek.“, nebo varují: „Trigger je v tomto popisku víckrát.“
  • BRIA JSON: Naformátovat JSON JSON odsadí. Při uložení se ověří.
  • MiniMax H3: při uložení se ověří jeho tři pole.

Když přepnete na jiný obrázek s neuloženými úpravami, Caption Studio se zeptá, zda je zahodit.

Klipy

U klipu panel kontroly ukazuje:

  • přehrávač,
  • rozměry, délku, snímkovou frekvenci, počet snímků a zvuk,
  • na čem se zvolený video model trénuje (například „WAN 2.2 (A14B) se trénuje při 16 fps s nejvýš 81 snímky, asi 5 s.“),
  • snímky poslané modelu, každý se svým časem,
  • záložku pro každý video soubor popisku.

Snímky ukazují přesně to, co model viděl. Pokud mu uniká rychlý pohyb, nastavte Snímky z klipu pro analýzu na každých 0,25 s (kapitola 3.6).

12Soubory, data a soukromí

Soubory popisků

  • Popisky se ukládají vedle obrázků v kódování UTF-8: obrazek.jpg → obrazek.txt.
  • Každý výstup má vlastní soubor; uložení jednoho nikdy nezmění ostatní.
  • Nahrazovaný popisek se nejprve bajt po bajtu zazálohuje do .caption-backups.
  • Pokud se soubor popisku změní mimo Caption Studio (v jiném editoru), nepřepíše se. Pro pokračování načtěte dataset znovu.
  • Původní obrázky a klipy se nikdy nemění.

Datová složka

Vše, co aplikace ukládá, je ve složce data vedle CaptionStudio.exe (instalátor: %LOCALAPPDATA%\Programs\Caption Studio\data).

Položka Obsah
settings.json Recept, připojení a jazyk rozhraní (bez klíčů)
keys.json API klíče, šifrované pro váš účet Windows
session.json Otevřený dataset, návrhy a odpovědi modelu
runtime\models Stažený model a jeho obrazová část
runtime\model.log Diagnostika vlastního modelu
logs, app.log Záznamy aplikace, bez popisků, obrázků a klíčů

Datová složka přežije aktualizace i odinstalaci. Uložené klíče fungují jen pro váš účet Windows; na jiném počítači je zadejte znovu. Pokud do složky programu nelze zapisovat, data se ukládají do %LOCALAPPDATA%\CaptionStudio a aplikace to oznámí.

Soukromí

  • Lokální režim (Marvin, jiný lokální server nebo vlastní model): obrázky nikdy neopustí váš počítač. Spodní lišta píše Lokální režim · obrázky zůstávají na tomto počítači.
  • Cloudový režim: poskytovateli se posílají zmenšené kopie vybraných obrázků (nebo snímky klipů) bez EXIF metadat a recept. Spodní lišta uvádí, na jakou adresu.
  • Klíče šifruje Windows (DPAPI) a ukládají se zvlášť pro každou adresu.
  • Aplikace běží jen na vašem počítači (127.0.0.1) a ze sítě není dostupná.
